# Document 1: Project Description & Product Goal

## Project Name
MCP Integration for AI Agents with Public Transport Schedules and Vehicle Location System in Poznań

## Problem Statement
The City of Poznań publishes open public transport data in internationally recognized standards: GTFS (timetables, routes, stops) and GTFS-Realtime (GPS vehicle positions, real-time delays, disruption alerts). This data is critical for urban services, yet there is currently no solution enabling its integration with agentic AI systems.

## Product Goal
To design and implement a server compliant with the MCP (Model Context Protocol). This server will fetch GTFS and GTFS-Realtime data, process it, and expose it as tools callable by AI assistants within a conversation context. The ultimate goal is to allow busy commuters to have natural, quick conversations via CLI or UI agents about transit—asking questions about departures, real-time delays, and transport accessibility across Poznań.
